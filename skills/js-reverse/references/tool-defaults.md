# Tool defaults

- `js-reverse_list_network_requests`: first page of defaults, then paginate
- `js-reverse_search_in_sources`: default `excludeMinified=true`
- `js-reverse_get_script_source`: read small slices; full source via `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: only URL fragments that hit stably
- `js-reverse_get_paused_info`: start at `frameIndex=0`
